# FINN — Financial Investment Agent

FINN is a mobile-first prototype for a public-markets investor. It brings portfolio announcements, end-of-day market signals, and source-backed company research into one workflow.

**Live prototype:** [FINN on Render](https://finn-backend-b4j5.onrender.com/)

> The free Render service may take a little time to wake up after inactivity.

## What FINN does

### Portfolio briefing

FINN displays a prioritised digest of corporate announcements across a mock portfolio of NSE-listed companies. It also highlights end-of-day price and volume moves using configurable thresholds.

Filings and prices have separate freshness indicators. When a refresh fails, FINN can show a labelled, dated saved copy instead of treating missing data as an empty result.

The portfolio can be edited in the browser. In the demo version, those selections are stored on the device rather than synced across devices.

### Company research

Enter an NSE ticker to request a short brief based on available annual reports and earnings-call transcripts. FINN attempts to find and extract relevant primary-source documents, then uses an open-weight Qwen model through Groq to generate findings.

The brief can include:

- A business overview
- Management outlook
- Selected financial figures
- Source links, PDF pages, and supporting passages

If a document or finding cannot be retrieved or checked, FINN reports the gap. Research can be partial, and a valid ticker does not guarantee that all documents are available.

### Guidance versus outcome

A worked Hindustan Unilever example brings together a management guidance statement and a later reported figure. FINN labels them **not directly comparable** because the quoted guidance and reported outcome differ in period and do not establish matching scope.

### Saved results

FINN attempts fresh research first. If it cannot refresh, it may show a clearly dated saved result for the same company. If no suitable saved result is available, it reports the error and offers a retry.

The app identifies the provenance of saved material, including where an answer was written by the builder rather than generated by the model.

## Key decisions

- **Primary sources for research:** company annual reports and earnings-call transcripts are used as evidence. Findings link to the underlying documents.
- **Rule-based filing priority:** announcement categories help rank the digest; the priority is a heuristic, not a prediction of market impact.
- **Checks before display:** the research flow checks items against retrieved passages and withholds findings that fail its checks. Matching a quote or number does not, by itself, establish that a claim preserves the full meaning or context.
- **Graceful fallbacks:** dated snapshots and saved results keep the prototype usable when a source or model is unavailable.
- **Open-weight model:** Qwen is accessed through a configurable hosted model interface. The application does not require a GPU on the user’s device.

## Data sources

| Data | Source |
|---|---|
| End-of-day price and volume | Yahoo Finance |
| Corporate announcements | NSE |
| Annual reports and transcripts | Links discovered through Screener, exchange filings, and supported company investor-relations sites |
| Research generation | A configured Qwen model through Groq |

Prices are the latest available **end-of-day close**, not a live intraday price feed. Data access and document availability can vary by company and source.

## Running locally

### Prerequisites

- Python
- A Groq API key for live model requests

Create a virtual environment and install the project dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Create a local environment file from the example:

```bash
cp .env.example .env
```

Add your Groq API key to `.env` as `FINN_LLM_API_KEY` and review the other settings in `.env.example`. Do not commit `.env` or API keys.

Start the app:

```bash
uvicorn app.main:app --reload
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

To run the test suite:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

## Limitations

- **Coverage varies.** FINN can attempt research beyond its demo companies, but not every NSE-listed company has accessible reports or transcripts through the supported sources.
- **Research can be slow.** Document downloads, PDF extraction, model rate limits, and the free hosting tier can make a brief take several minutes.
- **Claims require judgment.** Automated checks help identify unsupported output but do not guarantee that a claim preserves every condition, segment, or qualification in the source.
- **Filings may be delayed or unavailable.** A failed refresh is shown separately from a successful check that found no filings.
- **Saved data has an age.** The interface labels saved results and snapshots; temporary server-side data may be lost when the free instance restarts.
- **Portfolio persistence is local to the browser.** It is not a brokerage connection or a synced investment account.
- **Demo sign-in is not authentication.** It personalises the prototype on the current device and is not intended to protect sensitive information.

FINN is a prototype for research and demonstration, not investment advice.
